# Raster/Pixel
- Verlauf: Kacheln nur via `RasterTileStore`. Pixel: Grenzen nur `raster/RasterPolicy`, Jobs atomar via `CadApp.commitRasterJob`; Ablehnung = Vektor bleibt.
- Lokaler CAD-Stand: IndexedDB (`raster/localScenePersist.ts`, Format `RASTER_FORMAT`) ist maßgeblich; Pixel nur als Hash-Blobs im Manifest (`raster/rasterManifest.ts`), localStorage nur Vektorstand – höheres Format wird nie geladen/überschrieben.
- RAM: Kachelpuffer nur über `raster/RasterResourceManager` (LRU, nur saubere Kacheln verdrängbar); verdrängt = unbekannt, nie transparent; Änderungen an ladenden Kacheln laufen über die `pending`-Warteschlange.
- Konsumenten: Masken melden `complete`; unvollständig = `RasterNotReadyError`, nie leer. Öffnen lädt nur Referenzen (`restore` dekodiert nie, Mehrfachketten über `lazyTileSrc`); `draw` lädt nur Sichtbares + 1 Kachel Rand; Ausgaben nur portionsweise über `drawRegionAsync` – nie alles vorab laden.
- Auflösung je Kachel: Faktor `s` (Halbierungsstufen, Weltgröße gleich); bestehende Kacheln werden nie umgerechnet (nur auf feinere Stufe gehoben), Komposition nimmt die feinste Stufe. Automatische Reduktion nur für neue Aktionen über `RasterPolicy.chooseActionScale` (nie Text/Muster/feine Striche).
- Vollflächen ohne Muster/Verlauf/Beschriftung liegen kompakt (`RasterLayer.addFill`, Manifest `solidFill`) und werden nur in lokal bearbeiteten Kacheln materialisiert; Musterflächen ebenso als `patternFill` (Mustertransformation in Welt, eigene Musterbilder einmal als Blob-Hash), Zeichnen nur über `paintCompactFill`.
- Große Jobs: Ergebnisse nur kodiert (Temp-Ablage), Zusammensetzung kachelweise (`composeForCommit`), Abschluss ohne Dekodierung (`replaceTilesLazy`) mit Versionsprüfung.
- Cloud: Manifeste nur über `raster/rasterCloud.ts` → `raster_publish_manifests` (alle offenen Keys + Referenzen in einer Transaktion); Outbox/`cloudBase`/Konfliktstände im lokalen Datensatz, Entscheidung je Key nur `decideRasterKey` (beidseitig geändert = Konflikt, beide Stände erhalten); Uploads nur via `uploadWithQuota` (Vorab-Größengrenze → Reservierung der Obergrenze → Upload → Bestätigung mit echter Größe); alle genutzten Assets referenzieren; Löschen nur claim → Storage-API → finalize. SQL: `db/migrations/20261010120000_storage_quotas_v2.sql`.
- Pixel werden nie mehr als Text (Data-URL) in localStorage gespeichert; Altstände werden beim Öffnen in IndexedDB übernommen und erst nach erfolgreichem Schreiben ersetzt.
- Lokale Blobs löscht nur `gcBlobs` (gespeicherte Stände + Konfliktstände + `sessionHashes`), nie während eines Speichervorgangs.
- Export: Ausschnitte zeichnen Rasterebenen über `CadApp.projectionRaster` (verknüpft = `sheet:<id>`, eingefroren = Kopie `frozen:<projId>` aus `freezeProjectionRaster`); PDF nur portionsweise über `drawRegionAsync`, unvollständig = Abbruch.
